# Metric definitions

| Metric | Definition | Denominator / limitation |
| --- | --- | --- |
| Paired CPP | Sum cost for matched rated packages / matched rated packages | Same population for both carriers |
| Paired coverage | Both-rated packages / eligible packages | Report missing baseline, missing scenario, both missing |
| Gross entitlement | Baseline package cost − scenario package cost | Positive means scenario saves before MM cost |
| EPP | Gross entitlement / comparison packages | Label historical vs converted volume |
| Net weekly savings | Converted weekly entitlement − weekly MM cost | No mixing total-period entitlement and weekly cost |
| SPL | Net weekly savings / weekly loads | Strict > threshold for economic flag; not a launch approval |
| ADV | Packages / explicitly defined observation days | Calendar-day and operating-day ADV differ |
| DEA | On-time packages / eligible EDD population | State maturity, missing EDD, weather exclusions, and no-POD treatment |
| OnTrac share | OnTrac volume / stated eligible carrier population | Explicitly state whether FedEx Express, USPS, Rx, and Freezer are included |
| WMS allocation gap | Actual allocated volume − modeled allocated volume | Compare same FC/ZIP/day/package constraints |

Avoid averaging lane CPPs or percentages without their denominator weights. Preserve full cost precision until presentation rounding.
